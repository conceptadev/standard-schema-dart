# Code of conduct

We want participation in this project to be safe, respectful, and productive.

## Expected behavior

- Be considerate of different backgrounds and levels of experience.
- Discuss ideas and code on their merits.
- Give actionable feedback and assume good intent.
- Respect boundaries and stop behavior when asked.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, personal attacks,
doxxing, or sustained disruption are not tolerated.

## Reporting

Report conduct concerns privately to a Concepta organization owner. Maintainers
will protect the reporter's privacy, review the available evidence, and take
proportionate action. Possible responses include a warning, content removal,
temporary restriction, or permanent removal from the project.

Maintainers are responsible for applying this policy fairly in repository
issues, pull requests, discussions, and other project spaces.
